如何使用

  1. 拖拽或选择多个 PDF 文件；
  2. 填写“每份页数”或选择“目标文件大小限制”，至少二者之一；
  3. 点击“开始拆分并打包”，等待生成 ZIP；
  4. 结果会出现在下方历史列表中，可随时下载；刷新页面也将保留。

FAQ

Q：支持哪些拆分方式？
A：支持两种策略：按“每份页数（page）”或按“目标大小（size）”。二者至少填一个，若同时填写，后端会综合处理。
Q：page/size 的单位是什么？
A：page 为份内页数（≥1 的整数）；size 为字节数（如 1MB=1048576）。页面提供了常用预设（10KB/100KB/1MB/10MB/100MB/1GB）。
Q：背后使用了哪些技术？
A：后端基于 Spring Boot 构建，使用 Apache PDFBox 进行 PDF 拆分、Java ZipOutputStream 进行 ZIP 打包，文件可上传至腾讯云 COS 存储。
Q：为什么需要用户 ID？
A：接口路径包含 {userId} 以便未来扩展用户级隔离与审计。目前页面默认以 0 占位提交。
Q：安全方面如何考虑？
A：建议在服务端通过环境变量/加密配置注入 COS 密钥，限制单次上传大小与并发，必要时加入限流，详见 README 的“安全性增强”。
Q：性能如何优化？
A：可考虑异步队列/分布式处理、优化内存占用与缓存重复文件。详见 README 的“性能优化方向”。
Q：历史列表是否持久？
A：前端使用 localStorage 存储历史记录（仅保存文件名、大小、时间与临时 URL），刷新页面仍可见；你可随时点击右上角“清空历史”。
